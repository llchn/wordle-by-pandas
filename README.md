# Wordle Desktop Game
A desktop implementation of the popular word-guessing game Wordle, built from scratch using Java and the Swing GUI toolkit.

## Overview
This project replicates the core mechanics of the original game, including dictionary validation and color-coded feedback. We also engineered a high-contrast toggle mode to make the UI accessible for low-vision and colorblind players.

## Tech Stack
Language: Java
GUI Framework: Java Swing (javax.swing)
Concepts applied: OOP, Event-driven architecture, State management
